C/C++ Pointers Cheat Sheet

1. What is a Pointer?

A pointer stores the memory address of another variable.

    int x = 10;
    int* p = &x;

    std::cout << *p; // 10

-   &x = address of x
-   p = pointer storing the address
-   *p = dereference (value at that address)

------------------------------------------------------------------------

2. Why Pointers Exist

Pointers are used for: 1. Dynamic memory allocation 2. Passing data
without copying 3. Building data structures (linked lists, trees,
graphs) 4. Interfacing with hardware and operating systems

------------------------------------------------------------------------

3. malloc() and free() (C)

Single Variable

    int* p = (int*)malloc(sizeof(int));
    *p = 42;

    free(p);

-   Allocates raw memory.
-   Does NOT call constructors.
-   Must be released with free().

Array

    int* arr = (int*)malloc(5 * sizeof(int));

    for (int i = 0; i < 5; i++)
        arr[i] = i * 10;

    free(arr);

------------------------------------------------------------------------

4. new and delete (C++)

Single Variable

    int* p = new int(42);
    delete p;

Array

    int* arr = new int[5];

    for (int i = 0; i < 5; i++)
        arr[i] = i;

    delete[] arr;

Rule:

-   new -> delete
-   new[] -> delete[]

Never mix them.

------------------------------------------------------------------------

5. Constructors and Destructors

    class A
    {
    public:
        A()  { std::cout << "Constructor\n"; }
        ~A() { std::cout << "Destructor\n"; }
    };

    A* obj = new A();
    delete obj;

new: 1. Allocates memory 2. Calls constructor

delete: 1. Calls destructor 2. Frees memory

------------------------------------------------------------------------

6. Object Lifetime

Stack Object

    A obj;

Destroyed automatically at the end of the scope.

Heap Object

    A* obj = new A();
    delete obj;

Lives until delete is called.

------------------------------------------------------------------------

7. malloc vs new

  malloc           new
  ---------------- --------------------
  C                C++
  Raw memory       Creates objects
  No constructor   Constructor called
  free()           delete

------------------------------------------------------------------------

8. Raw Pointer Problems

Dangling pointer

    int* f()
    {
        int x = 5;
        return &x;
    }

Memory leak

    int* p = new int;
    p = nullptr;

Double delete

    delete p;
    delete p;

------------------------------------------------------------------------

9. std::unique_ptr

    #include <memory>

    class A {};

    int main()
    {
        {
            auto p = std::make_unique<A>();
        } // object automatically destroyed here
    }

Characteristics

-   One owner
-   Cannot copy
-   Can move ownership
-   Automatic cleanup
-   Preferred smart pointer

Ownership transfer

    auto p1 = std::make_unique<A>();
    auto p2 = std::move(p1);

After move: - p1 == nullptr - p2 owns the object

Arrays

    auto arr = std::make_unique<int[]>(5);

------------------------------------------------------------------------

10. std::shared_ptr

    auto p1 = std::make_shared<A>();

    {
        auto p2 = p1;
    } // p2 destroyed

    // object still alive

Object is deleted only after the final shared_ptr is destroyed.

Reference count

Create -> 1

Copy -> +1

Destroy copy -> -1

Count reaches zero -> object deleted

------------------------------------------------------------------------

11. std::weak_ptr

Used with shared_ptr to avoid circular references.

    std::weak_ptr<A> wp = sp;

    if (auto p = wp.lock())
    {
        // safe to use
    }

------------------------------------------------------------------------

12. Choosing the Right Pointer

  Situation                  Recommendation
  -------------------------- --------------------------
  Local object               Stack variable
  Single owner               unique_ptr
  Multiple owners            shared_ptr
  Observer only              weak_ptr
  Non-owning API parameter   Raw pointer or reference

------------------------------------------------------------------------

13. Modern C++ Philosophy

Raw pointers generally do NOT own memory.

Ownership should usually be expressed using:

-   stack objects
-   unique_ptr
-   shared_ptr

------------------------------------------------------------------------

------------------------------------------------------------------------

15. Key Takeaways

-   malloc/free manage raw memory only.
-   new/delete manage objects and their lifetime.
-   Prefer stack allocation whenever possible.
-   Use unique_ptr by default for heap objects.
-   Use shared_ptr only when ownership is genuinely shared.
-   Use weak_ptr to observe shared objects without extending their
    lifetime.
-   Think in terms of ownership and lifetime, not just memory
    allocation.
